# Bitki EKG — Uygulamalı Yapay Zeka Dönem Projesi

İnsan EKG'siyle önceden eğitilmiş derin öğrenme modellerinin bitki elektrik sinyallerine aktarımı:
domateste sulama stresinin tespiti (zaman serisi sınıflandırma).

## Branch'ler

- `donem-projesi`: Dönem projesinin kendi yaptığım sürümü (bu branch).
- `onDeneme`: Yapay zekâ (Claude) yardımıyla yapılmış ön deneme.
